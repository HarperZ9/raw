# Ray-traced shadows with alpha, facets and sky visibility (docs/RAYTRACING.md): each view the game,
# ours without and with rays, then the views of the sun visibility (View=2) and sky visibility
# (View=4), and A/B by hot reload: alpha-tested meshes out (RtAlpha=0), sky off (RtSky=0).
start load rawharness
console tai
scene riverwood_day
console set gamehour to 13
wait 12
keyframe still steps=game,improved_no_rt,improved,improved_rt hold=60
reload ini RtAlpha=0
