# The game's weather drives the surfaces end to end (rt_weather.cpp -> PG_SetWeatherState -> WeatherDrive.h):
# Riverwood by day, forced to a rain weather (10a241) and then a snow weather (c8221, flags 8 read back in game) with fw. The engine module reports the
# weather it reads (formId and flags) at each stage; the engine light list joins the decoded one (SceneLights).
# Short soak, puddle and snow times so one session shows each stage. View=8: wet red, puddles green, snow blue.
start load rawharness
console tai
scene riverwood_day
console set gamehour to 12
wait 12
engine weather
keyframe dry steps=game,improved hold=60
console fw 10a241
wait 8
engine weather
keyframe turning steps=game,improved hold=30
wait 30
engine weather
keyframe raining steps=game,improved hold=60
reload ini View=8
keyframe raining_masks steps=improved hold=20
reload ini View=0
console fw c8221
wait 10
engine weather
keyframe to_snow steps=improved hold=30
wait 40
engine weather
keyframe snowing steps=game,improved hold=60
reload ini View=8
keyframe snowing_masks steps=improved hold=20
reload ini View=0
quit
