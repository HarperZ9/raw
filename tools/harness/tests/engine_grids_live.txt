# Live grid size. Startup grids 7 ([EngineSet] uGridsToLoad=7, cell buffer 64) sizes the cell array for 7 x 7.
# Interiors keep the exterior grid loaded, so `grids <n>` waits for the game to empty the array (a save
# load) and lands then. The same vista from the save, 12,000 units up, at 7, 5 and 7 again,
# with the loaded cells reported after each load. Then the live light list by day, at night and in the inn.
start load rawharness
scene grids
wait 4
engine grids
bat tcl|player.setpos z 12000|player.setangle x 15
wait 15
engine grids; measure vista_g7 600; capture vista_g7
engine grids 5
console load rawharness
wait 8
bat tcl|player.setpos z 12000|player.setangle x 15
wait 15
engine grids; measure vista_g5 600; capture vista_g5
engine grids 7
console load rawharness
wait 8
bat tcl|player.setpos z 12000|player.setangle x 15
wait 15
engine grids; measure vista_g7b 600; capture vista_g7b
engine lights; live 120; weather
console tai
console set gamehour to 22
wait 8
engine lights
console coc whiterunbanneredmare
wait 8
engine lights; wait 400; live 0
quit
